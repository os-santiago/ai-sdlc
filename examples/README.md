# Examples

This directory contains contract archetypes that consumers can use as starting points for their own `.ai-sdlc.yaml` files.

- [internal-app.ai-sdlc.yaml](internal-app.ai-sdlc.yaml) — internal app — aggressive ceiling. Full autonomy up to auto-merge-all.
- [library.ai-sdlc.yaml](library.ai-sdlc.yaml) — public library — conservative ceiling. Trust never exceeds auto-merge-low.
- [org-baseline.ai-sdlc.yaml](org-baseline.ai-sdlc.yaml) — org-wide floor template. Sets the autonomy ceiling at auto-merge-low for repositories.
