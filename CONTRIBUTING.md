# Contributor Guidelines

Thank you for considering contributing to this project! Please read the following guidelines to ensure your contributions are accepted smoothly.

## Developer Certificate of Origin (DCO)

To ensure a clear licensing trail, we require contributors to sign off on their commits. By adding a `Signed-off-by` line to your commit message, you certify that you have the right to submit the contribution and agree to the DCO terms.

### How to sign off

When committing, use the `-s` flag with `git commit`:

```bash
git commit -s -m "Your commit message"
```

This will automatically add a `Signed-off-by` line with your name and email as configured in your git settings.

### Agent commits

Commits made by automated agents (e.g., AI-sdlc-runtime[bot]) are exempt from the DCO sign-off requirement. These commits are generated by the project's automated pipeline and are considered to be made on behalf of the project.

## Contributor Vouch

To protect against low-quality or malicious first-time contributions, we require that a project maintainer vouch for any contributor's first pull request. This is done by a maintainer leaving a comment on the PR indicating their endorsement (e.g., "I vouch for this contributor.") or by approving the PR.

Once a contributor has had one PR accepted, they are considered trusted and subsequent PRs do not require a vouch.

## Commit and Branch Conventions

Please follow the conventions outlined in the project's [AGENTS.md](./AGENTS.md) for branch naming, commit messages, and pull request descriptions.

- Branch names: `fix/issue-N-<slug>` / `feat/issue-N-<slug>` / `docs/<slug>`
- PRs should reference issues: `Closes #N` or `Refs #N`
- Use squash merge and delete the branch after merging.

## Reporting Issues

If you encounter a bug or have a feature request, please open an issue on the GitHub issue tracker. Provide as much detail as possible, including steps to reproduce for bugs.

## Questions?

If you have any questions, feel free to ask in the issue tracker or reach out to the maintainers.
